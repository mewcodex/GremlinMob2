# 地精小队 · 二代移植

GremlinMob2 是面向 Mega Crit 的[《杀戮尖塔 2》（Slay the Spire 2）](https://store.steampowered.com/app/2868840/Slay_the_Spire_2/)的独立角色模组，已在游戏 **v0.114.0** 上验证。它把一代崩坠中的地精小队和可选娘化皮肤移植到二代。

二代移植作者为 **Alriph**。

五名成员各有 16 点生命，共用牌组、格挡和战斗状态。起始牌组为四张打击、四张防御、一张配合和一张地精之舞。起始遗物在开战首回合提供 1 点能量、额外抽 1 张牌并换到下一位。换位会切换队首特性和独立生命值。队首倒下时，由下一名存活队员补位。

## 移植来源

- **Downfall（崩坠，一代）**由 The Downfall Collab Team 制作，是《杀戮尖塔》（Slay the Spire）的同人扩展。地精小队的角色规则、卡牌、专属遗物、药水及原始素材来自一代 Downfall JAR。本项目依据实际注册、本地化和字节码移植。 [Downfall 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=1610056683)
- **Downfall Feminization（崩坠娘化，一代）**是 Downfall 的皮肤模组。使用的档案版本为 **0.3.0**，其中的模组清单署名 **anaer、hoykj**。选人页的「娘化皮肤 by anaertailin」使用该模组的地精小队及地精大块头 Spine 素材，卡底贴图取自同一套皮肤。

此外，部分二代界面素材和角色接入方式参考 lamali 的二代 Downfall。运行 GremlinMob2 时可独立加载，重新构建资源包时需要本地素材。 [二代 Downfall 源码](https://github.com/lamali292/Downfall/tree/16937032fe623e06546a36cae81ca5318dfdc262/mod)

## 内容核对

- 附件注册了 77 张牌，对应 72 张奖励牌、4 张基础牌及护符。另有 5 张换位选项、爆裂及巨体生成的 3 张牌。
- 保留附件注册到地精小队自定义池的 14 件遗物，以及 3 种药水。原 Boss 遗物进入二代非涅奥先古的现有选项槽位。附件注册到共享池的补给卷轴和倒刺护盾已移除。
- [一代到二代的模型与图像映射](tools/catalog.ini)逐项列出。Echo 采用二代临时复制。
- PCK 包含一代源图、图层合成贴图、原始 3.4 JSON、Atlas，以及六套供二代引擎播放的 Spine 4.2 数据。选人裁图、队伍头像与轮廓、地图箭头、联机手势、转场与卡牌拖尾采用二代崩坠地精小队的专用资源。营地与倒地继续使用一代 `shoulder2.png` 和 `corpse.png`。选人背景与二代崩坠的 `selection_screen.png` 像素相同。

## 战斗站位与换位

队首使用二代房间给出的玩家原点，包括帝皇蟹战的原生居中点。后备保留一代每格 90 的左向槽距、生命数字和悬停说明。换位时新队首立即占据玩家原点，后备沿一代的每帧插值前移，存活的原队首加入尾部。倒下的队员退出战斗队列，战斗内复活加入尾部。巨体阻止换位时显示附件原话，遗物触发的换位保持无对白。附件中的一代音效调用引用的是一代游戏的音效库。

临时生命沿用一代 StSLib 的金色血条描边和右侧盾牌图标。盾牌贴图按 MIT 许可随资源包分发，描边纹理由一代游戏素材导入。 [StSLib 源码](https://github.com/kiooeht/StSLib/tree/3be4b65948d2d9810f4bff7053e34d4ae511adff/src/main/java/com/evacipated/cardcrawl/mod/stslib/patches/tempHp)

## 二代角色接口与旧存档

单人选人页面可在「传统模式」和「超模模式」之间切换，选择随新开局保存。超模模式下，赢得战斗后会让阵亡地精以 1 点生命复活，地精墓碑可点选一名队员并将其恢复到满血。

角色资源接入二代的 `CharacterModel` 入口。对可覆盖的资源属性直接覆盖，对固定文件名使用 Godot 资源重映射。模组可独立加载。角色适配参考 [lamali 二代崩坠的角色模型](https://github.com/lamali292/Downfall/blob/16937032fe623e06546a36cae81ca5318dfdc262/mod/DownfallCode/Abstract/DownfallCharacterModel.cs)。

选人页的左右箭头来自一代崩坠的皮肤选择界面。「娘化皮肤 by anaertailin」使用 anaer 和 hoykj 的 Downfall Feminization 0.3.0 中五名地精和巨体的 Spine。地精美术模式的卡底贴图由同一套 Spine 的静态画面裁出，按原版贴图的位置打包。选人立绘与头像保持原图，皮肤选择保存在本机，在战斗、商店和卡底贴图上生效。商店中的娘化角色播放原有待机动画。战斗中，娘化后排的悬停区域按体型限制宽度，并随每个模型的高度调整。

升级首领之角时，升级遗物接手原来的队伍顺序和各成员生命值。旧档同时持有两件角时，读取时也会将队伍状态转移到升级遗物。角被熔化时，角本身的额外抽牌、能量和换位奖励失效，队伍状态仍参与战斗结算。队首被动用附件状态图标和原版说明显示在状态栏。

## 血量事件迁移

| 一代行为 | 二代适配 |
| --- | --- |
| 知识骷髅、诅咒之书、残骸黏液、感知石、翼之雕像等事件代价分摊 | 非战斗事件中，通用生命损失折为原值除以五并向上取整，对所有存活成员结算。选择提示考虑后排能否补位。实测垃圾堆。 |
| 幽灵议会、吸血鬼的最大生命代价 | 二代最大生命代价按成员折算并更新存活后排上限。安息地实测。真理石板先换算再进行原生致死判断，最后一次按成员剩余最大生命结算。深渊浴场按增益和伤害分别换算后的净代价提示。 |
| 治疗、李氏华夫饼的队伍特例 | 固定数值事件治疗分摊，按百分比计算的漩涡治疗直接应用给每位成员。安息地和茶会的全回复作用到所有活着的成员。华夫饼同时恢复后排。模拟休息继续使用原生营地治疗及复活规则。 |

该适配使用二代已有事件。第一代的专属剧情、概率表与音效未加入。偷来的商品保留换位生成 Echo 和原商店价格。一代商人战与腐化之心的额外力量触发依赖对应遭遇，二代当前版本没有移植这些遭遇。

## 构建与验证

角色和卡池入口在 `Character/`，卡牌按基础、攻击、技能、能力、衍生和先古分布在 `Cards/`，每张牌的数值和结算在同一个文件中。队伍存档与换位、战斗被动、生命变化在 `Roster/`。原生接口补丁、显示资源及一代文案转换分别在 `Patches/`、`Presentation/` 和 `Localization/`。模型类名参与生成存档 ID，归档文案和资源索引也使用这些类名。

需要 .NET 9、Godot 4.5.1 和本机《杀戮尖塔 2》。重新导入素材需要 Python 和 Pillow。用 `GameDir` 指定二代安装目录，`GodotExe` 指定 Godot 命令行程序，`DownfallJar` 指定一代 Downfall JAR。用 `Sts1AssetsDir` 指定含 `powers/powers.atlas`、`powers/powers.png` 和 `images/potion` 的一代资源目录。若本机有经转换的对应 Spine 数据，可用 `NativeRigsDir` 指定六个原角色名子目录的上级目录，每个子目录应有对应的 PNG 和 `.spskel`。省略时使用构建脚本转换的 JSON。

```powershell
dotnet build .\GremlinMob2.csproj -c Release `
  "-p:GameDir=<杀戮尖塔2安装目录>" "-p:GodotExe=<Godot命令行程序>" `
  "-p:DownfallJar=<一代Downfall.jar>" "-p:Sts1AssetsDir=<一代游戏素材目录>" `
  "-p:DownfallGremlinsDir=<二代Downfall的Gremlins素材目录>"
```

产物在 `build\GremlinMob2`。退出游戏后，将其中的 `GremlinMob2.dll`、`GremlinMob2.pck` 和 `GremlinMob2.json` 放入二代安装目录下的 `mods\GremlinMob2`。测试项目在 `checks`，实机探针在隔离用户目录 `GremlinMob2Smoke-114` 运行。

重新导入娘化皮肤时，给构建命令添加 `"-p:FeminizationArchive=<DownfallFeminization.rar>"`。构建使用支持读取 RAR 的 `tar` 提取地精资源。

实机探针使用固定种子和测试用生命值加速首领回合，借助二代的出牌、奖励、换幕、建筑师和胜利结算流程验证通关。覆盖五名队员的被动、换位、临时生命、复活、巨体模式、三种药水、事件生命结算和存档。该测试未覆盖正常路线的平衡、所有出牌组合或联机。

## 文案与能量资源

游戏内角色名和介绍、卡牌及升级说明、遗物、药水与能力文案来自一代语言文件。缺少对应语言条目时使用一代英文原文。经确认的卡牌文案修正集中在 `tools/card_text_corrections.json`，其余显示处理沿用原文，只转换换行、关键词标记、数字变量和能量图标语法。

卡牌费用使用一代的 1024 图标，行内能量使用从 512 图集中裁出的原始小图，分别贴合二代对应控件尺寸。战斗能量盘使用一代的六层贴图、暗色贴图及能量特效，控件尺寸与二代崩坠一致，为 128×128。

地精美术模式按一代卡牌标签决定牌面下方的地精贴图。贴图从一代卡框提取，显示在二代描述下层。卡牌预览与关键词解释使用一代内容，地精之舞的五个变体每 0.9 秒轮换一次。

点开卡牌详情时优先显示一代的高分辨率卡图，缺少对应大图时使用普通卡图。

状态小图和触发闪光用的大图分别进入二代原生资源路径。临时力量和束缚从一代 `powers.atlas` 提取，临时荆棘、临时生命、法力和就绪时的爆裂使用附件资源。药水按一代瓶身、液体颜色和轮廓合成静态贴图。普通战斗和帝皇蟹战共用 1.0 的模型比例，按各房间的原生相机缩放。
